# Planning with Files

触发条件：任务涉及 3+ 个步骤、跨多个文件、或用户说"做个计划"。

## 步骤

1. **建计划文件**：在项目根目录创建 `.plan.md`——
   ```markdown
   # 任务计划
   - 目标：
   - 预计步骤：
   - 开始时间：
   - 状态：🟡 进行中
   
   ## 步骤进度
   - [ ] Step 1:
   - [ ] Step 2:
   ```
2. **每完成一步**：更新 `[ ]` → `[x]`，加一行备注
3. **遇到障碍**：在计划中记录 blocker + 尝试过的方案
4. **完成后**：状态改为 ✅，保留文件作为记录

## 规则

- 不创建多余的中间文件（如 NOTES.md、TODO.md），统一用 `.plan.md`
- 计划文件跟代码一起 commit，方便回溯
